// 04 Technical Projects

Things I've Built

Audio-Reactive LED Lighting System
★ ECE 1100 Discovery Project Python Teensy LC WS2812B Embedded Systems
[ Add a photo of the completed perfboard assembly / LED strip in action ]

This project is a complete, hardware-level build of an audio-reactive LED lighting system designed for a DJ controller. The system takes live audio from DJ software, processes it in real time, and drives a physical LED strip, all through a custom-built embedded pipeline with no external power supply required.

System Overview

Audio is captured from Serato on macOS using BlackHole, a virtual audio device that routes the DJ software's output directly into a Python processing script, no microphone, no latency-inducing analog capture. The Python script continuously reads the audio stream, computes real-time volume levels, and encodes that data as serial commands.

Those commands are transmitted over USB serial to a Teensy LC microcontroller, which acts as the embedded brain of the system. The Teensy parses incoming volume data and maps it to dynamic color patterns and brightness levels on a WS2812B addressable LED strip. Because the WS2812B requires 5V logic and the Teensy operates at 3.3V, a 74AHCT125 level shifter was incorporated into the design to bridge the voltage gap and ensure clean, reliable signal transmission to the LEDs.

[ Add a system block diagram: Mac → BlackHole → Python → USB Serial → Teensy LC → 74AHCT125 → WS2812B ]

Hardware & Power Design

All components, the Teensy, level shifter, and supporting passives, are soldered to a perfboard for a clean, permanent installation rather than a fragile breadboard prototype. This was an intentional choice: soldering to perfboard demonstrates hardware discipline and produces a system reliable enough for real-world, repeated use in a DJ setting.

[ Add a close-up photo of the soldered perfboard assembly ]

Skills Demonstrated & Relevance

This project spans the full embedded systems stack: software (Python audio processing, serial communication), firmware (Teensy microcontroller programming, LED control via the FastLED library), and hardware (level shifting, perfboard assembly, power budgeting). It reflects the kind of end-to-end systems thinking that employers in embedded engineering, consumer electronics, and robotics look for, the ability to own a problem from software architecture down to the physical hardware layer.
